Release notes and download checksums ↗

Early evaluation release.

The apps are not yet publisher-signed or notarized. Windows or macOS may warn or block them; do not disable operating-system protections. Windows Home and ARM Windows are not supported yet. Real customer VM installation and physical air-gap testing remain under evaluation.

1. Open Nomiarch Setup

Choose Set up this computer. The app checks your computer and guides you through installing VM support if it is missing. Windows may request administrator approval and a restart to enable Hyper-V.

Reserve 8 GB of memory and at least 50 GB of free disk space for the first evaluation. A small Linux VM will house Core, the model and your system data.

2. Let the app prepare the files

Choose Download and verify automatically. Nomiarch downloads the runtime, local model and matching Ubuntu image, checks the files and verifies the Core signature. You see download progress in the app.

Already inside an isolated environment? Choose Use files I brought into this environment. This mode checks the local kit without downloading anything.

3. Review and install

Choose a system name, keep the recommended settings, and select Create my Nomiarch system. The app creates a new VM, installs Core and checks it using the real local model. Your existing VMs are left in place.

4. Try your first task

When setup says Your system is ready, open Manage my installation and choose Verify. It runs the sample configuration check and records the result. Two deliberately failing sample controls and one passing control are expected.

This preview includes setup, local inference, policy checks and evidence. Core does not yet have a browser dashboard or perform live infrastructure repairs.

5. Maintain it from the same app

Return to Manage an installation for Verify, Repair, Upgrade, Back up or Saved status. Upgrade asks you to select the approved new bundle and public key, creates an encrypted backup, installs the release and checks the result. The app helps you save a new private recovery key; keep it safely apart from the backup.

Expect downtime during upgrades. K3s migrations and automatic rollback are not supported in this preview. Detailed recovery procedure ↗

Preparing an offline installation

On a connected computer, choose Download an offline kit. Transfer the kit and desktop app to a computer with the same CPU architecture through your approved process. Install VM support on that computer before isolation.

The app works with an existing isolated host and administration network. It does not create a physical air gap by disconnecting your computer.

Finished testing?

In Manage, select the exact installation and choose Remove selected VM. The app asks before permanently deleting it. Save any backup you need first.

If setup stops

The app shows the error and preserves installation records. Retry a download to reuse verified completed files. For an interrupted installation, use Manage to inspect, repair or remove the retained VM. Starting a new install creates another VM.
